# Offline Common300 evidence

This bundle makes the historical three-model comparison inspectable from a clean
Git checkout. It contains the original saved raw responses, embedded answers and
metadata for all 300 charts in each arm, plus the recovered synthetic_v0 and
synthetic_v1 training splits (3,500 rows each) and Modal synthetic_v1 test split
(1,000 rows). No API account, GPU, Modal credentials or external dataset is needed
to **rescore** these outputs. This is not a new inference run.

From the repository root, with the project's locked Python dependencies installed:

```sh
python -m analysis.reproduce_common300
```

The command verifies every compressed and uncompressed artifact hash and row
count, frozen Modal split membership, exact Common300 prediction coverage, and
each prediction's truth and metadata against the saved test split. It checks both
training splits for table overlap, then scores saved `raw` responses using the
current `chart-table-v2` contract and `chart-json-v2` parser. It does not trust the
old parsed `pred` field. Missing or modified evidence stops the command before a
new report is written. The output is `outputs/common300-reproduced.json`; pass
`--out /path/report.json` to choose a destination.

For an unconfigured checkout, use Python 3.11 and the same setup as CI:

```sh
python3.11 -m venv .venv
. .venv/bin/activate
python -m pip install --require-hashes -r requirements-dev.lock
python -m pip install --require-hashes -r requirements-build.lock
python -m pip install --no-deps --no-build-isolation -e .
python -m analysis.reproduce_common300
```

## Results and overlap checks

| Saved arm | Semantic cell F1 within 5% | Raw semantic validity |
|---|---:|---:|
| Base 4B, pinned Hub revision | 6.59% | 71.67% |
| Fair table LoRA | 28.90% | 95.33% |
| Table LoRA with numeric loss | 26.67% | 93.67% |

Paired chart bootstrap: 10,000 resamples, seed 0, all 300 IDs, pooled semantic cell
F1. Fair minus base is **+22.31 percentage points**, 95% interval **[18.98, 25.71]**.
Numeric loss minus fair is **−2.23 points**, interval **[−3.97, −0.61]**. Unlabeled
pies remain a separate proportion proxy; 280 charts contribute to exact numeric
table rates. The fair arm has only 13/280 exactly correct charts. These scores
show useful improvement over the base and substantial remaining extraction error.

Both recovered training splits have **zero matching Common300 tables** under:

- The existing historical signature: chart family, ordered named series, sorted
  x/y points with y rounded to six decimals; title and axes ignored; 64-bit hash.
- An additional full SHA-256 signature: sorted series of sorted x/y points,
  ignoring chart family, series names/order, title and axes. Series grouping,
  x identities, point multiplicity and exact parsed numeric values are retained.

The v1 training IDs are disjoint from Common300. The v0 split reuses 158 numeric
IDs across dataset versions, but their tables differ under both checks. IDs are
scoped to dataset versions. Neither check detects all near-duplicates, relabeled
x categories, transformed values or pretraining contamination.

## Provenance and limits

`manifest.json` records original `/vol` source paths, raw-byte SHA-256, compressed
SHA-256, uncompressed byte counts and row counts. Gzip members preserve the source
bytes exactly and were generated with timestamp zero. The small `*.meta.json`
files preserve original run metadata without additions. Their hashes and those
of the committed subset/split definitions are also checked. The generated report
records the manifest hash and current scorer/parser/auditor source hashes.
Hashes detect changes relative to this Git version; they are not third-party
attestations of how the historical files were produced.

The synthetic charts and labels were generated by this project; the included
responses are its saved Qwen3-VL experiment outputs. The repository license is
Apache-2.0. This bundle includes no model weights, customer uploads, third-party
real-chart images or frontier-provider responses. Model provenance remains in the
original metadata and [third-party notices](../../THIRD_PARTY_NOTICES.md).

Important limitations of this evidence:

- Common300 was reused during development. It is a synthetic regression set,
  **not an untouched final holdout or evidence of real-world generalization**.
- Image paths remain historical references; original image bytes are not bundled.
  Reproducing generation or visually checking the labels needs a separate image
  and renderer provenance package. This command only verifies saved table data.
- The fair and numeric-loss model revisions are old directory fingerprints, not
  weight content hashes. Available training files and run metadata do not prove
  the exact data consumed by an immutable training job. Reproducing the weights
  requires a frozen training recipe, checkpoints and training-data identities.
- Historical files account for 300 saved responses per arm, but have no durable
  dispatch ledger or generation finish reasons. They cannot establish absence of
  earlier discarded attempts/retries or compliance with today's production
  completion contract. New local runs use the [attempt ledger](../evaluation-ledger/README.md).
- Complete frontier comparison, real_v0 visual-truth audit, current deployed
  preprocessing quality, runtime/cost benchmarks and independent real holdout
  evaluation remain open. No additional training is justified by packaging alone.

CI tests rescore the bundle against the recorded strict scores, require the
training-overlap audit without a private-file skip, and exercise missing/corrupt
artifacts, missing/extra/duplicate predictions and changed truth/metadata.
